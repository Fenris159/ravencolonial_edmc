# Oxanium (bundled)

[Oxanium](https://fonts.google.com/specimen/Oxanium) by Severin Meyer is included under the
[SIL Open Font License 1.1](OFL.txt). You may bundle and redistribute it with this plugin.

Files:

- `Oxanium[wght].ttf` — variable font (weight axis 200–800)
- `OFL.txt` — license text

On startup, when EDMC Modern Overlay is installed, the plugin copies the variable font into
`EDMCModernOverlay/overlay_client/fonts/` and sets `preferred_fonts.txt` so the HUD uses Oxanium.
